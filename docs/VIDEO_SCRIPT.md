# 60-second demo script

Record the website in a browser at 1280x720. Read the voice lines at a calm pace.

| Time | Screen | Voice |
|---|---|---|
| 0:00 to 0:06 | Hero: "Vision can't feel." | "Robots increasingly ask a vision model: did I succeed? For contact tasks, that question is harder than it looks." |
| 0:06 to 0:20 | "Can you tell?" game. Pause on two near-identical images, click one. | "Same scene, same camera. In one, the cube touches. In the other it hovers a millimeter above. Which one succeeded?" |
| 0:20 to 0:30 | Reveal panel: ground truth, model verdicts, sensor sparklines. | "Here is the truth from the simulator, what each free vision model said, and what three cheap sensors read." |
| 0:30 to 0:40 | Leaderboard, then the noise chart. | "Across five contact tasks, a tiny classifier on noisy, cheap sensors beats the vision models, until the noise gets large enough." |
| 0:40 to 0:50 | Millimeters-to-fool chart. | "An attacker searches for the biggest failure a model still calls a success. Some models stay fooled by gaps of several millimeters." |
| 0:50 to 0:57 | Leaderboard push column and the limitations section of the README. | "Sensors are not magic: a single-axis force sensor misses sideways pushes, and the classifiers do not transfer to new tasks." |
| 0:57 to 1:00 | GitHub link. | "Everything is open: code, data, and every model answer." |

Check every number you say against the live leaderboard before recording.
